# Custom card art

Drop your own images in this folder. Any card without an image automatically uses the built-in design, so you can replace just a few.

**Format:** PNG (best), WebP or JPG. If you use WebP/JPG, change `ext` in `CFG` at the top of the script in `index.html`.
**Size:** 400 x 600 px (2:3 portrait). 800 x 1200 also works. Keep each file under about 150 KB.
**Corners:** draw full-bleed with square corners. The game rounds them. Keep text and art at least 28 px away from the edges.

## File names (all lowercase)
Colors: `red`, `yellow`, `green`, `blue`

- Numbers: `red-0.png` ... `red-9.png`
- Actions: `red-draw2.png`, `red-draw4.png`, `red-reverse.png`, `red-skip.png`, `red-skipeveryone.png`, `red-discardall.png`, `red-7swap.png`, `red-0swap.png`
- Same names for `yellow-`, `green-` and `blue-`
- Wilds: `wild-reversedraw4.png`, `wild-draw6.png`, `wild-draw10.png`, `wild-colorroulette.png`, and the chaos cards `wild-67.png`, `wild-7blocks.png`, `wild-megareverse.png`, `wild-snipe10.png`, `wild-pillow.png`, `wild-hearts.png`
- Card back (draw pile): `back.png`
