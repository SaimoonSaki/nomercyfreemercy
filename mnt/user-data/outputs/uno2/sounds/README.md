# Soundboard sounds

Drop your own sound files in this folder. No code changes needed: every file shows up as a button on everyone's soundboard (the file name becomes the label, `-` and `_` become spaces).

**Formats:** MP3 (best), WAV, OGG or M4A.
**Length and size:** keep clips short (under about 5 seconds) and each file under about 200 KB, so they load fast on the free server.
After adding files, push them to GitHub and let Render redeploy. A few built-in beeps are always there.

## Chaos mode stingers
Name a file `chaos-67`, `chaos-7blocks`, `chaos-mega`, `chaos-snipe`, `chaos-pillow` or `chaos-heart` (any format above) to replace the built-in sound for that card. These files do not appear on the soundboard.
